# nelsongaitan.com

Portfolio site for Nelson Gaitan, product designer in Miami. Plain HTML, CSS and a little JavaScript, hosted on GitHub Pages.

## Pages
- `index.html` home
- `work/guest-hub.html`, `work/linked-events.html`, `work/mo.html` case studies
- `about.html`
- `brain-grace.html`

Shared styles live in `assets/site.css`, interactions in `assets/site.js`, images in `assets/img`.
